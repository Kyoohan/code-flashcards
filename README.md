# 코드 플래시카드

코드/개념 암기를 위한 단일 HTML 파일 플래시카드 앱입니다. 빌드 과정이나 서버 없이 `index.html`을 브라우저로 열기만 하면 바로 사용할 수 있습니다.

## 주요 기능

- **여러 덱(과목별 카드 세트) 관리** — 과목/시험별로 덱을 만들고 상단에서 전환
- **두 가지 학습 모드**
  - 전체 코드 타이핑 모드 (줄바꿈 무시, 공백 정규화 후 비교)
  - `{{정답}}` 문법으로 빈칸을 지정하는 빈칸 채우기 모드 (하이라이팅 유지)
- **오답 재출제(SRS)** — 틀린 문제만 모아 다음 라운드에 다시 출제, 완전히 맞힐 때까지 반복
- **학습 통계** — 카드별 정답률과 취약 카드 TOP 8을 보여주는 통계 패널
- **카드 검색/필터** — 편집기에서 설명·코드로 카드 검색
- **다크모드**
- **로컬 저장 + 선택적 영구 저장** — 기본은 브라우저 `localStorage`에 자동 저장되며, Chrome/Edge에서는 로컬 JSON 파일에 연결해 영구 백업 가능 (File System Access API)
- **가져오기/내보내기** — 덱 단위로 JSON 내보내기·가져오기 (다른 사람과 카드 세트 공유 가능)

## 사용 방법

1. `index.html`을 브라우저로 엽니다 (더블클릭하거나 `file://` 경로로 접속).
2. 우측 상단 **편집** 버튼으로 카드를 추가합니다.
   - 문제 설명과 정답 코드를 입력합니다.
   - 정답 코드에 `{{정답}}` 형태로 빈칸을 표시하면 빈칸 채우기 모드로 출제됩니다.
3. 문제를 풀고 **확인**을 누르면 정답 여부를 확인할 수 있습니다. 빈칸 모드는 Enter로 각 빈칸을 개별 채점합니다.
4. 상단 **통계** 버튼에서 카드별 정답률을 확인할 수 있습니다.
5. 여러 과목을 관리하려면 좌측 상단 덱 선택기에서 **＋** 버튼으로 새 덱을 만드세요.

### GitHub Pages로 배포하기 (선택)

레포지토리 Settings → Pages에서 배포 브랜치를 지정하면 별도 서버 없이 링크로 바로 접속해 사용할 수 있습니다.

## 데이터 저장 방식

카드/진행 상황/통계는 브라우저의 `localStorage`에 덱별로 저장됩니다. 브라우저 데이터를 지우면 사라지므로, 중요한 카드는 **내보내기**로 JSON 백업을 남기거나 **파일 연결하여 영구 저장** 기능으로 로컬 파일에 연결해 두는 것을 권장합니다.

## 기술 스택

Tailwind CSS(CDN), highlight.js, jsdiff — 별도 빌드 과정 없이 CDN으로 로드됩니다.
